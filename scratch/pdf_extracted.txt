🔍Validação Automática de NúmeroNOVO
Todos os endpoints de envio agora validam automaticamente se o número
existe no WhatsApp antes de enviar. Isso evita envios para números inválidos e
retorna erro 400 imediatamente.
Comportamento Padrão
A validação é ativada por padrão para números individuais
Grupos (@g.us) e broadcasts não são validados
Se o número não existir no WhatsApp, retorna erro 400
Desativar Validação
Se você já validou o número previamente ou quer pular a validação por
performance, adicione validateNumber: false no body:
{
  "jid": "5511999999999@s.whatsapp.net",
  "text": "Olá!",
  "validateNumber": false
}
 Dica: Use o endpoint GET /api/instances/:id/check-number/:phone para
validar números em lote antes de enviar, e depois envie com
validateNumber: false para melhor performance.

PostgreSQL é o storage persistente. Isso proporciona leituras extremamente
rápidas (~1ms) com a segurança de persistência do PostgreSQL.
